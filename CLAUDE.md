# Proje: Sıra Tabanlı Yandan Görünümlü RPG (oyun adı: **Embers of Valdoria**; repo/klasör adı ve `proto.*`/`protomedi.*` localStorage anahtarları değişmez)

## Özet
Armor Games'teki Sonny tarzı, yandan görünümlü (side-view), 2D pixel art, sıra tabanlı RPG.
Web tabanlı (TypeScript + Phaser 3 + Vite), mobil tarayıcıda da oynanır.
4 kişilik takım (hızlı savaş varsayılanı 4; sefer 1-4), düğüm tabanlı dünya haritası, hıza göre dinamik sıra sistemi.

## Sahip ve çalışma biçimi
- Proje sahibi (Ömer) **kod okumaz/denetlemez**. Kalite güvencesi: otomatik testler, oyun içi debug menüsü, denge simülasyon raporları.
- Ömer ile iletişim **Türkçe**, kod diliyle değil sade dille. Her görev sonunda: ne yapıldı, hangi ekranda nasıl görünmeli, ne test edilmeli.
- Ömer'in "çerçevesi" `docs/design/` altındadır. Orada yazmayan bir tasarım kararını kendi kafana göre verme: varsayım yaptıysan görev sonunda açıkça söyle ve `docs/design/open-questions.md` dosyasına ekle.
- Küçük adımlar: her adım sonunda oynanabilir bir şey çıkmalı.
- Ana oturum koordine eder; gerektiğinde `.claude/agents/` altındaki agentları çağırır ve sonuçları Ömer'e tek özet olarak sunar.
- **Agent görev adları (Ömer 2026-10-09):** her agent başlatılırken açıklaması (Background tasks'ta görünen ad) agent türüyle başlar: `<tür>: <iş>` (ör. `ui-dev: battle HUD mockups`, `engine-dev: melee reach bug`, `balance-tester: Endless balance`, `content-designer: summon VFX`, `campaign-dev: item MVP`, `endless-dev: gear bag`, `multiplayer-dev: ...`). Tür `.claude/agents/` altındaki rollerden biridir; genel amaçlı agent kullanılsa bile açıklama işin rolüyle başlar.

## Komutlar
- `npm run dev` — geliştirme sunucusu (`--host` açık: aynı Wi-Fi'deki telefondan da açılır)
- `npm run build` — tip kontrolü + üretim derlemesi (`dist/`)
- `npm test` — vitest testleri (motor saflığı denetimi dahil: `src/engine` içinde Math.random/Phaser/DOM yasak)
- `npm run sim` — headless denge simülatörü (`src/sim/cli.ts`): rastgele takımlı savaşlar, iki taraf yapay zeka; sınıf kazanma oranı (4e 4; hedef bantlar `data/balance.json`: kazanma %44-56, bedelsiz temel saldırı %20-45, normal skill %15-35, durumsal destek %8-25, ultimate hazır olana kadar yaşayanlarda en az bir kez ≥%50, süre 35-50 tur; karakter karşı karakter tablosu yalnızca ezici eşleşmeleri işaretler), kompozisyon, skill kullanımı raporu. Argümansız 2 x 10.000 savaş; seçenekler: `npm run sim -- <savaş sayısı> <ilk seed> [oyuncu] [düşman]`. `tests/balance.test.ts` + `tests/balance-b.test.ts` aynı ölçümü test olarak korur.
- `npm run sim:campaign` — sefer simülatörü (`src/sim/campaign.ts`): seferi baştan sona YZ ile oynar (oyuncu vekili Medium = iyi oyuncu, Easy = ortalama oyuncu), üç zorluk; düğüm başına ilk deneme kazanma, deneme sayısı, kalan can, rota bitirme. Hedefler `data/campaign/balance.json`; testler `tests/campaign-balance.test.ts`, `tests/campaign-difficulty.test.ts`.
- `npm run sim:endless` — Endless simülatörü (`src/sim/endless.ts`, CLI `endless-cli.ts`): koşuları YZ ile baştan sona oynar (iyi oyuncu vekili: ödül/dükkân/Equip best/kalıntı), dalga başına kazanma, ulaşma eğrisi, p10/p50/p90, elit/boss düşüşü, sınıf ve kalıntı etkisi; `--compare` (item'siz / kalıntısız), `--cfg=dosya.json` (veriye dokunmadan ayar denemesi). Hedef bantlar `data/endless.json > balance`; test `tests/endless-balance.test.ts`.
