# Embers of Valdoria

Sıra tabanlı, yandan görünümlü, medieval fantezi RPG (TypeScript + Phaser 3 + Vite). Valdoria seferi, hızlı savaş ve çok oyunculu mod. Tarayıcıda ve telefonda oynanır.

Geliştirici notları ve kurallar: `CLAUDE.md`. Tasarım çerçevesi: `docs/design/`.

Komutlar: `npm run dev`, `npm test`, `npm run build`, `npm run sim`.
