> Create ONE image, 1536x1024, transparent background: a sprite sheet of 20 game icons in a 5-column x 4-row grid, row by row left to right. Each icon is centred in its own cell with generous empty transparent space around it, nothing touching the cell edges, no grid lines, no text, no letters, no numbers, no labels.
> Style: match the attached icon sheet exactly — painted medieval fantasy UI icons, crisp dark outline, warm gold/brass and parchment tones with one clear accent colour per icon, soft top-left light, slight emboss. Each icon must read instantly as a silhouette at 24x24 px, so keep shapes bold and simple, one symbol per cell, no backgrounds, no frames, no circles behind the symbol.
